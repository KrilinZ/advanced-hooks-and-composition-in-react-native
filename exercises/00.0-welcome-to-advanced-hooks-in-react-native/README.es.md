# 00.0 Bienvenido a Hooks Avanzados en React Native

¡Bienvenido al curso de **Hooks Avanzados en React Native** con TypeScript!

En este curso, descubrirás cómo usar hooks poderosos como **useRef**, **useMemo**, **useCallback** y patrones de composición de componentes para mejorar el rendimiento y la calidad de tus aplicaciones móviles.

Aprenderás a manejar referencias, optimizar cálculos costosos, memorizar funciones y reutilizar lógica compleja, todo con ejemplos prácticos y ejercicios.

Al finalizar, tendrás las habilidades para escribir código más eficiente, limpio y fácil de mantener, mejorando la experiencia de usuario en tus proyectos.

¡Prepárate para llevar tus conocimientos de React Native al siguiente nivel!
